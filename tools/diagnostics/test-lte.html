Проверка заказа без VPN

Как создать тестовую функцию
  1. В Яндекс Облаке откройте Cloud Functions → Создать функцию. Для новой версии выберите Node.js 22 и загрузите ZIP с кодом. Точка входа index.handler, память 128 МБ, тайм-аут 50 секунд.
  2. В переменных окружения функции задайте TELEGRAM_BOT_TOKEN (токен вашего бота), CHAT_IDS (два числовых ID через запятую) и TEST_KEY (ключ ниже). Используйте бота, который уже может писать в оба чата.
  3. Создайте версию и разрешите публичный вызов функции. Скопируйте ссылку для вызова. После проверки публичный вызов можно выключить.

Отключите Wi-Fi и VPN. Проверка связи не отправляет сообщений. Кнопка отправки передаст карточку, три тестовых фото и текст в оба чата.
