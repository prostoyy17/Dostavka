# MayrMarket

Доставка продуктов по Грозному из магазинов города. Цены и наличие берутся из каталогов самих магазинов.

Сайт: https://prostoyy17.github.io/Dostavka/

## Структура

```
index.html            каркас страницы: шапка, нижняя панель, подключение файлов
css/
  styles.css          весь внешний вид, светлая и тёмная тема
js/
  config.js           настройки доставки: часы, цена доставки, порог бесплатной доставки, склады
  icons.js            иконки интерфейса (SVG)
  app.js              логика: страницы, корзина, избранное, поиск, фильтры, оформление заказа
data/
  catalog.js          каталог товаров (Musafir Market, Parhato, Kindar Product)
  photos.js           наши собственные фото для товаров без фото в магазине
assets/
  brand/              логотип, иконки (вкладка, экран «Домой»), картинка превью ссылки og-logo.png
  icons/              картинки категорий (3D)
  photos/             файлы наших фото товаров
favicon.ico           иконка вкладки для старых браузеров
manifest.webmanifest  название и иконка, когда сайт добавляют на экран телефона
tools/
  bump-version.sh     новая версия сайта для сброса кэша браузера
.nojekyll             нужен GitHub Pages, чтобы отдавать файлы как есть
```

Сайт статический: HTML, CSS и JavaScript без фреймворков и без сервера. Корзина, избранное, адрес и заказы
хранятся в браузере покупателя (localStorage).

## Где что менять

| Что | Где |
| --- | --- |
| Часы работы (`hours: [9, 25]` — с 9:00 до 01:00 ночи), время и цена доставки, бесплатно от | `js/config.js`, массив `POINTS` |
| Включить выбор складов в шапке | `js/config.js`, `WAREHOUSES_ENABLED = true` |
| Цвета светлой темы | `css/styles.css`, блок `:root` в начале |
| Цвета тёмной темы | `css/styles.css`, блок `:root[data-theme="dark"]` |
| Логотип и иконки сайта | `assets/brand/` (фирменный синий `#0033B0`, один и тот же в обеих темах) |
| Добавить своё фото товару | файл в `assets/photos/`, строка в `data/photos.js` (`"магазин:id товара": "путь"`) |
| Иконки интерфейса | `js/icons.js` |

## Формат каталога

`data/catalog.js` задаёт `window.CATALOG = { meta, cats, items }`.
Каждый товар в `items` — массив:

```
[id, название, цена, категория, номер подраздела, фото, весовой (1/0), остаток,
 предложения [[магазин, id в магазине, цена], ...], большое фото | 0, старая цена]
```

Показывается самая низкая цена; в карточке товара — цены во всех магазинах, где он есть.

## Выпуск новой версии

1. Внести изменения.
2. `tools/bump-version.sh` — иначе у покупателей может остаться старая версия из кэша.
3. Закоммитить и отправить:
   ```
   git push origin main
   git push origin main:gh-pages
   ```
   GitHub Pages публикует ветку `gh-pages` (в ней та же история, что в `main`). Обновление появляется на сайте через 1–2 минуты.
