# MayrMarket

MayrMarket-Доставка продуктов в Грозном

Сайт: https://prostoyy17.github.io/Dostavka/

## Структура

```
index.html            каркас страницы: шапка, нижняя панель, подключение файлов
css/
  styles.css          весь внешний вид, светлая и тёмная тема
js/
  config.js           настройки доставки: часы, цена доставки, порог бесплатной доставки, склады
  icons.js            иконки интерфейса (SVG)
  app.js              логика: страницы, корзина, избранное, поиск, фильтры, оформление заказа
data/
  catalog.js          каталог товаров Musafir Market и Вкусдома
  photos.js           наши собственные фото для товаров без фото в магазине
assets/
  brand/              логотип, иконки (вкладка, экран «Домой»), картинка превью ссылки og-logo.png
  icons/              картинки категорий (3D)
  p/                  копии фото Parhato (их сервер отдаёт фото с неправильным типом, iPhone их не показывает)
  photos/             файлы наших фото товаров
favicon.ico           иконка вкладки для старых браузеров
manifest.webmanifest  название и иконка, когда сайт добавляют на экран телефона
tools/
  bump-version.sh     новая версия сайта для сброса кэша браузера
.nojekyll             нужен GitHub Pages, чтобы отдавать файлы как есть
```

Сайт статический: HTML, CSS и JavaScript без фреймворков и без сервера. Корзина, избранное, адрес и заказы
хранятся в браузере покупателя (localStorage). Сервер MayrMarket отправляет карточку товаров, до трёх фото входа и текст заказа двум получателям в Telegram. Заказ сохраняется после подтверждения доставки Telegram хотя бы в один чат.

## Где что менять

| Что | Где |
| --- | --- |
| Часы работы (`hours: [9, 25]` — с 9:00 до 01:00 ночи), время и цена доставки, бесплатно от | `js/config.js`, массив `POINTS` |
| Номер WhatsApp для заказов | `js/config.js`, `ORDER_WHATSAPP` |
| Включить выбор складов в шапке | `js/config.js`, `WAREHOUSES_ENABLED = true` |
| Включить прилипающую шапку с поиском (как у Ozon) | `js/config.js`, `STICKY_HEADER = true` |
| Цвета светлой темы | `css/styles.css`, блок `:root` в начале |
| Цвета тёмной темы | `css/styles.css`, блок `:root[data-theme="dark"]` |
| Логотип и иконки сайта | `assets/brand/` (фирменный синий `#0033B0`, один и тот же в обеих темах) |
| Добавить своё фото товару | файл в `assets/photos/`, строка в `data/photos.js` (`"магазин:id товара": "путь"`) |
| Иконки интерфейса | `js/icons.js` |

## Формат каталога

`data/catalog.js` задаёт `window.CATALOG = { meta, cats, items }`.
Каждый товар в `items` — массив:

```
[id, название, цена, категория, номер подраздела, фото, весовой (1/0), остаток,
 предложения [[магазин, id в магазине, цена], ...], большое фото | 0, старая цена]
```

Показывается самая низкая цена; в карточке товара — цены во всех магазинах, где он есть.

## Выпуск новой версии

1. Внести изменения.
2. `tools/bump-version.sh` — иначе у покупателей может остаться старая версия из кэша.
3. Закоммитить и отправить:
   ```
   git push origin main
   ```
   GitHub Pages публикует корень ветки `main`. Статус публикации виден во вкладке Actions.

## Поиск, приложения и обработчик заказов

- `js/catalog/search.js` индексирует каталог для поиска по названию, категории и подразделу в выбранном магазине.
- `js/catalog/recommendations.js` хранит интерес к категориям и недавние показы в браузере. Сайт отправляет общему обработчику только суммы действий по категориям. Общий рейтинг учитывает текущую и предыдущую неделю. Просмотр, поиск, избранное, корзина и покупка влияют на новые подборки.
- `tools/diagnostics/` содержит страницы проверки связи. Старые адреса в корне перенаправляют на них.
- Каталог iOS собирается из тех же данных через `ios/prepare.mjs`. Запись с симулятора хранится в ветке `ios/simulator-preview` в `preview/native-store/`.
- Исходник опубликованного обработчика хранится в `server/checkout/worker.mjs`. Для обновления в Sites тот же файл копируется в `dist/server/index.js` проекта обработчика. Привязка R2 `BUCKET` хранит выданные номера.
- Короткий номер перед отправкой резервируется в общем обработчике заказов. Каждая резервация хранится отдельно, включая резервации для незавершённых заказов.

Иконки интерфейса предоставлены [Uicons by Flaticon](https://www.flaticon.com/uicons).

Для проверки каталога, поиска, рекомендаций и выдачи номеров запустите `node --test tests/*.test.mjs server/checkout/*.test.mjs`.
